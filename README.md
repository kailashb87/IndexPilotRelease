# 🚀 IndexPilot v1.0.0 — Official Launch!

Welcome to the initial official release of **IndexPilot**, the ultimate Windows desktop application built to streamline URL indexing workflows for SEO professionals, website owners, and digital marketers. 

Say goodbye to manually checking URLs or jumping between disconnected search engine tools. Monitor index status, submit requests, and manage your data—all from a single desktop interface.

---

## ✨ Key Features & Capabilities

### 🔍 Check Google Index Status
* **Bulk Verification:** Quickly verify whether your web pages are indexed in Google Search.
* **Smart Filtering:** Effortlessly identify which URLs are fully indexed and which ones still require attention.

### ✉️ Multi-Engine Indexing Requests
* **Google Search:** Submit URLs for indexing directly to Google to accelerate your visibility.
* **Microsoft Bing:** Submit URLs directly to Bing to ensure cross-engine coverage.
* **Unified Flow:** Notify both search engines about your new or updated content simultaneously.

### 📊 Excel Integration (Import & Export)
* **Bulk Import:** Load large lists of URLs straight from Excel sheets for rapid bulk processing.
* **Report Export:** Save your processing results back to Excel for easy client reporting, internal analysis, or record-keeping.

## ⚠️ Important Installation & First-Run Notes

Because IndexPilot is an independent software tool, please note the following security behaviors during installation:

1. **🛡️ Administrator Privileges Required:** 
   IndexPilot requires system-level execution to manage dependencies and process local file operations efficiently. The app will prompt you for **User Account Control (UAC) / Administrator rights** every time it launches. Click **Yes** to allow the application to function.
2. **🔵 Windows SmartScreen Warning:** 
   As a newly published independent desktop application, Windows might initially show a blue screen saying *"Windows protected your PC - Unknown Publisher"*. 
   * **To proceed:** Click **"More info"** on the blue popup, then click the **"Run anyway"** button to start the installation.
